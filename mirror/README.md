# מראה

אפליקציית צ'אט עם Claude בעיצוב חדש: כהה ומינימליסטי, RTL כברירת מחדל, תשובות בסטרימינג, עצירה באמצע תשובה, היסטוריה שנשמרת בדפדפן ומצב בהיר אוטומטי.

## הרצה

```bash
cd mirror
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python app.py
```

אחר כך נכנסים ל-http://127.0.0.1:5001.

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | מפתח ה-API |
| `MIRROR_MODEL` | `claude-opus-5-5` | המודל שבו משתמשים |
| `PORT` | `5001` | פורט |
| `HOST` | `127.0.0.1` | כתובת האזנה |

## הערות

- בשרת אין התחברות. כל מי שמגיע אליו משתמש במפתח שלך, ולכן ברירת המחדל היא האזנה מקומית בלבד. לפני חשיפה לאינטרנט צריך להוסיף אימות.
- זה צ'אט בלבד. אין כאן כלים לקריאת קבצים או להרצת פקודות כמו ב-Claude Code.
- ההיסטוריה נשמרת ב-localStorage של הדפדפן ולא בשרת.
