# מכות בכנסת · KNESSET SMACKDOWN

משחק לחימה סאטירי בדפדפן: 21 חברי כנסת ומנהיגי מפלגות קריקטוריים מ-17 מפלגות, לכל אחד יכולת מיוחדת ומכות משלו.
כל הדמויות הן דגמים תלת-ממדיים שנבנים בקוד ומוצגים ב-WebGL (בלי תמונות ובלי קבצי דגם), כל הצלילים והמוזיקה מסונתזים, ואין ספריות חיצוניות (הגופנים מ-Google Fonts אופציונליים, ויש גיבוי).
קובץ אחד, `index.html`, ואפשר לפתוח אותו ישר בדפדפן (גם בטלפון).

> **פרודיה וסאטירה.** הדמויות קריקטורות, וכל הציטוטים, היכולות והמכות בדויים. אין קשר בין המשחק לאף אחד מהמופיעים בו.
> הנתונים העובדתיים היחידים הם המפלגה והתפקיד של כל דמות, ונבדקו ב-30.9.2026. מקורות ופירוט ב-[DATA.md](DATA.md).

בטלפון מופיעים מקל תנועה וכפתורי מגע.

**שלט משחק (Xbox / פלייסטיישן / 8BitDo, ב-Chrome, Edge, Safari):** לוחצים על כפתור כלשהו כדי שהדפדפן יזהה אותו, ומופיעה הודעה. אחר כך אפשר לשחק ולנווט בכל התפריטים רק עם השלט:

| פעולה | כפתור |
|---|---|
| תנועה | מקל שמאלי או חיצים. למעלה קפיצה, למטה התכופפות, לחיצה כפולה לריצה |
| אגרוף · בעיטה | `X` · `Y` |
| **יכולת מיוחדת 1 · 2** | **`A` · `B`** (הסמל שמתחת לפס ההייפ מראה מתי היא מוכנה, ועליו האות של הכפתור) |
| חסימה (מחזיקים) | `LB` או `LT` |
| סופר (כשההייפ מלא) | `RB` |
| זריקה | `RT` |
| הפסקה | `Start` |
| בתפריטים | מקל/חיצים לניווט, `A` אישור, `B` חזרה, `Start` אישור מהיר, שמאלה/ימינה משנה מחוונים ורשימות |

בפלייסטיישן: ✕ = A, ○ = B, □ = X, △ = Y, L1 = LB, R1 = RB, R2 = RT. הסבר מלא עם איור: "איך משחקים", או "בקרות" בתפריט ההפסקה. ב-3 הקרבות הראשונים עם שלט מופיעה תזכורת על המסך.

**כפתור "חזרה" של הטלפון** (כפתור או החלקה מקצה המסך) לא יוצא מהמשחק באמצע קרב: הוא רק מזכיר איך עוצרים, ובהפסקה הוא ממשיך את הקרב. במסכי התפריט הוא חוזר צעד אחורה, ובמסך הראשי צריך ללחוץ פעמיים כדי לצאת.

**כל ההגדרות בזמן קרב נמצאות רק בתפריט** (כפתור "תפריט" > הגדרות): עוצמות, רעידות מסך, כפתורי מגע, מצב רוחב ומסך מלא. על מסך הקרב עצמו יש רק כפתור התפריט.

**טלפון על הצד:** המשחק מיועד לרוחב. אם הטלפון מוחזק לאורך, המשחק מסובב את הממשק ב-90° לבד (הכיוון נקבע לפי חיישן התנועה), מנסה להיכנס למסך מלא ולנעול רוחב, ובכותרת או ב"הגדרות" אפשר להפוך את הכיוון או לכבות את הסיבוב. לשני שחקנים על מקלדת אחת: שחקן 1 `WASD` + `F G H R T Y E`, שחקן 2 חיצים + `, . / ; ' Enter M`.

**בלי זום בטעות:** לחיצה כפולה וצביטה לא מגדילות את הדף (שם הדפדפן היה מזיז את המשחק ממקומו). החסימה בשלוש שכבות: תגית ה-viewport, `touch-action` ב-CSS, ומטפלי מחוות ב-JavaScript (`Game.zoomGuard`), כי ב-iOS Safari התגית לבדה לא מספיקה. כפתורים ושדות ממשיכים לעבוד כרגיל.

**מראה:** מסכים כהים בגווני פלדה עם ארגמן וכתום גחל וגופן כבד (Heebo). הכפתורים הם לוחות פלדה בהירים עם פס צבע בצד (אדום למסע, כחול לקרב רגיל, כתום למרתון, זהב ליומי), כדי שיבלטו מהרקע. הפנים: כל דמות מקבלת מספרים אישיים למבנה הפנים (אף, סנטר, מצח, גבות, עפעפיים, אוזניים, אורך ורוחב הראש, תסרוקת) ולבנה (גובה, רוחב, כתפיים, בטן), מוגזמים בכוונה. דיוק הדמיון נקבע מהידע הכללי על כל אחד, ללא תמונות ייחוס. הצבעים בראש `src/css/style.css` (`--crimson`, `--ember`, `--steel-*`), וב-`OUT` ב-`10-icons.js` לקווי המתאר בקנבס.

**אם בטלפון רואים רק מסך ריק:** כנראה הקובץ נפתח בתצוגה מקדימה של אפליקציה (ללא JavaScript). צריך לפתוח אותו בדפדפן עצמו, Chrome באנדרואיד או Safari באייפון ("פתח באמצעות"). אם המשחק נטען אבל איטי או תקוע, מוסיפים `?safe` לכתובת (או לוחצים "הפעלה במצב בטוח" במסך השגיאה): בלי תלת־ממד ועם פחות אפקטים.

## מצבים

- **קרב רגיל**: קרב אחד נגד המחשב. בוחרים לוחם, יריב (או "יריב אקראי"), קושי (קל / בינוני / קשה) וזירה, ובסוף אפשר עוד סיבוב, יריב אחר או לוחם אחר.
- **מסע לראשות הממשלה**: סדרת קרבות בשלוש רמות קושי (קל / בינוני / קשה), ובסוף בוס סודי (אחוז החסימה).
- **מרתון חקיקה**: גלים אינסופיים. אחרי כל ניצחון מעבירים "חוק" (שדרוג), והחיים עוברים לגל הבא.
- **האתגר היומי**: שלושה קרבות עם "חוק היום" שמשנה את הפיזיקה, זהה לכולם באותו יום.
- **קרב חברים**: שני שחקנים על אותו מסך. **אימון**: יריב שאפשר לכוון (עומד, חוסם, קופץ, נלחם), איפוס עמדות, הייפ אינסופי, תצוגת קלט, תיבות פגיעה, וקריאת נזק אחרון וקומבו. כל אפשרויות האימון בתפריט ההפסקה, ושם גם היציאה.
- דרגות והישגים. כל הלוחמים פתוחים מההתחלה, חוץ מדמות סודית אחת (אחוז החסימה, נפתחת אחרי סיום מסע).

## הרכב הלוחמים

כל לוחם: יכולת מיוחדת קבועה (פסיבית), שתי יכולות מיוחדות עם זמן טעינה, סופר קולנועי, ומכות רגילות בשמות משלו.
הפירוט המלא (בהדגמה חיה) במסך בחירת הדמות.

## פיתוח

```
knesset-game/
  index.html          המשחק הבנוי (קובץ יחיד)
  build.mjs           מדביק את src/ ל-index.html:  node knesset-game/build.mjs
  src/js/*.js         הקוד, לפי סדר המספרים (20 = תנוחות, 21 = ציור הלוחמים, 50 = זירות, 98-fightui = כפתור התפריט בקרב)
  src/css/style.css
  src/index.template.html
```

- הרשימה והמפלגות: `src/js/85-roster.js` (המפלגות ב-`PARTIES` ו-12 הלוחמים הראשונים), `86-roster2.js` ו-`87-roster3.js` (9 לוחמים נוספים), `88-boss.js` (הבוס הסודי). כדי לעדכן שיוך מפלגתי משנים את השדה `party` של הדמות, ואת התפקיד בשדה `role`.
- מראה הדמויות: `src/js/30-looks.js` (צבע עור, שיער, זקן, משקפיים, גיל, מבנה הפנים והגוף; בראש הקובץ רשימת כל השדות ו-`FG`, עוצמת ההגזמה של כל מאפיין). הדיוקנאות בבחירת הדמות, במסך הפתיחה לקרב ובממשק הם ציורים דו-ממדיים (`21-fighter-render.js`), והלוחמים בקרב תלת-ממדיים.
- תלת-ממד: `22-f3d-core.js` (הקשר WebGL2, שיידרים, תאורה), `23-f3d-geo.js` (גאומטריה: צינורות, אליפסואידים, מעטפות שיער), `24-f3d-paint.js` (טקסטורות פנים, בד, שיער, נוצרות בקנבס), `25-f3d-head.js` (ראש, פנים, שיער, זקן, אביזרים), `26-f3d-body.js` (שלד, גוף, בגדים, ציור ל-2D). הדמות מקבלת את אותן תנוחות כמו בגרסה הדו-ממדית, ובנוסף תאורה, נפח וסיבוב ראש וגוף. כמה דמויות שנטענו נשמרות (עד 16), ונבנות בזמן מסך הבחירה.
- גיבוי דו-ממדי: `21-fighter-render.js`. עובר אליו המשחק אוטומטית אם אין WebGL2 או אם הקצב יורד (הודעה קצרה על המסך), אפשר לכבות ב"הגדרות" (תלת-ממד), ואפשר לכפות עם `?flat` בכתובת.
- מוזיקה וצלילים: `src/js/60-audio.js`. `TRACKS.menu` הוא שיר הלובי (D מינור עם גוון פריגי, 124 פעימות לדקה, 32 תיבות שחוזרות: פתיחה, בית, בית עם הרמוניה, פזמון, פזמון, הפוגה, בית, פזמון אחרון), `battle` לקרב ו-`victory` לניצחון. הכול מסונתז בקוד.
- הוספת `?debug` לכתובת חושפת אובייקט `KS` בקונסולה (סימולציות, צילומי מצב).
