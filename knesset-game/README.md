# מכות בכנסת · KNESSET SMACKDOWN

משחק לחימה סאטירי בדפדפן: 21 חברי כנסת ומנהיגי מפלגות קריקטוריים מ-17 מפלגות, לכל אחד יכולת מיוחדת ומכות משלו.
כל הדמויות מצוירות בקוד (בלי תמונות), כל הצלילים והמוזיקה מסונתזים, ואין ספריות חיצוניות (הגופנים מ-Google Fonts אופציונליים, ויש גיבוי).
קובץ אחד, `index.html`, ואפשר לפתוח אותו ישר בדפדפן (גם בטלפון).

> **פרודיה וסאטירה.** הדמויות קריקטורות, וכל הציטוטים, היכולות והמכות בדויים. אין קשר בין המשחק לאף אחד מהמופיעים בו.
> הנתונים העובדתיים היחידים הם המפלגה והתפקיד של כל דמות, ונבדקו ב-30.9.2026. מקורות ופירוט ב-[DATA.md](DATA.md).

## איך משחקים

| פעולה | מקלדת (שחקן יחיד) |
|---|---|
| תנועה / קפיצה / התכופפות | `A` `D` `W` `S` או חיצים |
| אגרוף · בעיטה | `J` `K` (או `Z` `X`) |
| מיוחד 1 · מיוחד 2 | `L` `U` (או `C` `V`) |
| חסימה (מחזיקים) | `I` או רווח |
| סופר (כשההייפ מלא) | `O` או `B` |
| זריקה | `E` או `N` (או אגרוף + בעיטה יחד) |
| ריצה / נסיגה | לחיצה כפולה על כיוון |
| תפריט והפסקה | כפתור "תפריט" בראש המסך, או `Esc` / `P` (בשלט: Start) |

בטלפון מופיעים מקל תנועה וכפתורי מגע. יש גם תמיכה בשלט משחק.

**כל ההגדרות בזמן קרב נמצאות רק בתפריט** (כפתור "תפריט" > הגדרות): עוצמות, רעידות מסך, כפתורי מגע, מצב רוחב ומסך מלא. על מסך הקרב עצמו יש רק כפתור התפריט.

**טלפון על הצד:** מסתובבים לרוחב והמשחק מתאים את עצמו. אם האפליקציה נשארת נעולה על מסך לאורך, בכותרת (או ב"הגדרות") מפעילים "מצב רוחב", והמשחק מסובב את כל הממשק ב-90° לכיוון שנוח לכם. לשני שחקנים על מקלדת אחת: שחקן 1 `WASD` + `F G H R T Y E`, שחקן 2 חיצים + `, . / ; ' Enter M`.

## מצבים

- **מסע לראשות הממשלה**: סדרת קרבות בשלוש רמות קושי, ובסוף בוס סודי (אחוז החסימה).
- **מרתון חקיקה**: גלים אינסופיים. אחרי כל ניצחון מעבירים "חוק" (שדרוג), והחיים עוברים לגל הבא.
- **האתגר היומי**: שלושה קרבות עם "חוק היום" שמשנה את הפיזיקה, זהה לכולם באותו יום.
- **קרב חברים**: שני שחקנים על אותו מסך. **אימון**: יריב שאפשר לכוון (עומד, חוסם, קופץ, נלחם), איפוס עמדות, הייפ אינסופי, תצוגת קלט, תיבות פגיעה, וקריאת נזק אחרון וקומבו. כל אפשרויות האימון בתפריט ההפסקה, ושם גם היציאה.
- דרגות והישגים. כל הלוחמים פתוחים מההתחלה, חוץ מדמות סודית אחת (אחוז החסימה, נפתחת אחרי סיום מסע).

## הרכב הלוחמים

כל לוחם: יכולת מיוחדת קבועה (פסיבית), שתי יכולות מיוחדות עם זמן טעינה, סופר קולנועי, ומכות רגילות בשמות משלו.
הפירוט המלא (בהדגמה חיה) במסך בחירת הדמות.

## פיתוח

```
knesset-game/
  index.html          המשחק הבנוי (קובץ יחיד)
  build.mjs           מדביק את src/ ל-index.html:  node knesset-game/build.mjs
  src/js/*.js         הקוד, לפי סדר המספרים (20 = תנוחות, 21 = ציור הלוחמים, 50 = זירות, 98-fightui = כפתור התפריט בקרב)
  src/css/style.css
  src/index.template.html
```

- הרשימה והמפלגות: `src/js/85-roster.js` (המפלגות ב-`PARTIES` ו-12 הלוחמים הראשונים), `86-roster2.js` ו-`87-roster3.js` (9 לוחמים נוספים), `88-boss.js` (הבוס הסודי). כדי לעדכן שיוך מפלגתי משנים את השדה `party` של הדמות, ואת התפקיד בשדה `role`.
- מראה הדמויות: `src/js/30-looks.js` (צבע עור, שיער, זקן, משקפיים, גיל, ועוד), והציור עצמו ב-`src/js/21-fighter-render.js`: פרופורציות של מבוגר, בגדים וגפיים מוצללים, ופנים מפורטות במבט שלושה-רבעים.
- הוספת `?debug` לכתובת חושפת אובייקט `KS` בקונסולה (סימולציות, צילומי מצב).
