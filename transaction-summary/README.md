# מערכת סיכום עסקאות – דורון נועם מזרחי, עו"ד

מערכת ניהול עסקאות ושכ"ט צפוי, בעברית ו-RTL, הבנויה כעמוד אינטרנט יחיד (Single Page App) ללא שרת מאחורי הקלעים.

## איך פותחים את המערכת

אין צורך בהתקנה, שרת, או בנייה (build). פשוט פותחים את הקובץ `index.html` בדפדפן:

- **מקומית**: לחיצה כפולה על `index.html`, או הרצת שרת סטטי פשוט (`npx http-server` / `python3 -m http.server`) מתוך התיקייה הזו ופתיחת הכתובת שמוצגת.
- **אחסון פרטי**: מכיוון שזהו קוד סטטי בלבד (HTML/CSS/JS), ניתן להעלות את שלושת הקבצים (`index.html`, `style.css`, `script.js`) לכל אחסון קבצים סטטי פרטי (למשל GitHub Pages בריפו פרטי בתוכנית בתשלום, Netlify/Vercel במצב פרטי עם הגנת סיסמה, או פשוט שרת פנימי).

## הערה חשובה לגבי אבטחה

ביקשת מערכת ב"שרת פרטי שאף אחד לא יכול לפרוץ אליו". חשוב להבהיר: **אין באמת שרת אפשרות "בלתי ניתן לפריצה" באופן מוחלט**. הפתרון שנבחר כאן מצמצם את משטח התקיפה למינימום האפשרי בדרך הבאה:

- **אין שרת אחורי (backend) בכלל.** כל הלוגיקה רצה בדפדפן שלך בלבד. אין מסד נתונים מרכזי, אין API, ואין נקודת כניסה שאפשר "לפרוץ" אליה מרחוק - כי פשוט אין שם שרת שמריץ קוד.
- **הנתונים (העסקאות, היעד החודשי) נשמרים רק בדפדפן שלך** (LocalStorage), במכשיר שבו פתחת את הדף. הם לא נשלחים לשום מקום ברשת.
- המשמעות: אם תרצה לגשת לנתונים ממספר מכשירים, או לגבות אותם במקום מרכזי, יידרש בעתיד שרת אמיתי עם התחברות מאובטחת (משתמש/סיסמה, הצפנה) - זהו פרויקט נפרד וגדול יותר, ואשמח לבנות אותו אם תרצה.
- שמור על הריפו הזה **פרטי** ב-GitHub (Settings → Danger Zone → Change visibility), ואל תשתף את קובצי ה-HTML עם מי שלא אמור לראות את נתוני הלקוחות.

## תפקוד המערכת

- כפתור **"+ הוסף עסקה"** בפינה הימנית העליונה פותח טופס באותו עמוד (ללא ניווט/גלילה לעמוד אחר). שדות חובה: שם לקוח, שכ"ט משוער, תאריך סיום משוער (בורר תאריך). שדות לא חובה: סוג העסקה, מספר טלפון.
- בחירת **יעד הכנסה חודשי** (20K/30K/40K/50K) עם חישוב אוטומטי של הצפי השנתי.
- ציר חודשים לגלילה הצידה, כל חודש מציג את סך שכה"ט הצפוי ורשימת הלקוחות שלו.
- לחיצה על שם לקוח פותחת את פרטי העסקה, עם אפשרות לערוך שכ"ט, לסמן "קיבלתי את הכסף" או "לדחות תשלום" לתאריך אחר (מעביר את העסקה לעמודת החודש המתאימה).
- אם סך העסקאות בחודש חורג מהיעד, העסקה שגרמה לחריגה מסומנת בריבוע אדום עם סימן קריאה; לחיצה עליו מציעה להעביר אותה לאחד משני החודשים הבאים.
- אם אחד משני החודשים הקרובים עדיין לא הגיע ליעד, מופיע סימן אזהרה (⚠) ליד שם החודש.
- שעון ותאריך מתעדכנים בכל שנייה בפינה הימנית העליונה.
- במחשב אין גלילה כללית של העמוד (הכל נכנס למסך אחד); בטלפון העמוד נגלל באופן טבעי.

כל הנתונים נשמרים אוטומטית ב-LocalStorage של הדפדפן, כך שהם יישארו גם אחרי סגירת הדף וריענון.
